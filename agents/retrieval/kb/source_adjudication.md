# 数据源与取值裁决链（检索补参 Agent）

> 来源：Sysmods AI 方案 V1.1 §1.3.1 + V1.2 §8.2 脱敏规则
> 版本：kb-retrieval-v1.0 · 维护：检索补参 Agent

## 取值裁决链（禁止跳级）
① DESHY 实测/报价/项目数据 → ② 小型撬装市场公开数据（当期） → ③ 分布式应用文献/标准 → ④ 通用工业数据（仅兜底，必须标注"非分布式语境，精度降级"）。
检索查询按此链构建（先 DESHY 设备库，后市场，再文献）。

## 入库规则
- 每条数据带：数值、单位、出处 URL/文献、**日期**、裁决链等级、适用场景标签；
- 新鲜度：电价/政策/报价 >2 年须复核最新值；气象数据记录版本哈希；
- 冲突处理：同参数多源时按裁决链取高等级，差异>30% 时并列呈现由客户裁定（不擅自平均）。

## 分布式默认先验（§1.3.2 摘要）
- 电解：PEM/AEM 优先于 ALK；SOEC 仅在有余热时优先；
- 储氢：固态/低压优先于液氢；
- 电价对标柴油 1.5-2.5 元/kWh；偏远维护系数 1.5-2×；
- 优化目标：可靠性约束下 TCO 最低（保供率/自主天数硬约束）。

## 脱敏（泄密通道防线）
- 入 LLM prompt 与入检索查询**均须脱敏**：去客户标识/业主名/精确坐标（降为区域级）；
- 黑层资产（内部标定系数/报价策略）永不进入查询或 prompt；
- 涉军/涉边项目：直接建议 L3 私有化，不走云端检索。

## 输出格式
先验建议 = 数值区间 + 分布建议（三角/均匀）+ 置信度 + 出处 + 日期；
客户确认后升 A/B 级入参数卡；未确认保持 C 级并在报告中标注。
