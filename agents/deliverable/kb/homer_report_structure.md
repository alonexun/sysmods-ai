## 2. Cash Flow 明细表结构（本平台的成本表设计依据）

**行 = 成本类型 × 组件；列 = 年份（含第 0 年）；上下两段 = 名义值 / 贴现值；中缝一行 = 贴现因子。**

成本五类型（HOMER 口径，必须分清）：
1. **Capital 初始投资**：仅第 0 年；
2. **Replacement 替换投资**：设备寿命到期时发生（可非整年）；
3. **Salvage 残值**：项目期末按剩余寿命线性折算（正值流入）；
4. **O&M 运维**：年费（元/年）或按运行小时；电网购电支出减售电收入并入此类；
5. **Fuel 燃料**：燃料单价 × 年消耗量。

关键展示规则：
- 名义成本在上半表，贴现成本在下半表，中间列示**贴现因子**；
- 最后一行 = 各年总成本；右下角 = **Total NPC**（与优化表一致）；
- 图形化时可选"按成本类型堆叠"或"按组件堆叠"两种色板。

## 3. 优化结果表（Optimization Results）展示规则

- 每个配置一行，列：各组件容量、Total NPC、LCOE/LCOA、初始投资、年运维、保供率；
- **按 NPC 升序**，第一名高亮（HOMER 用蓝色选中态）；
- 允许"只看可行配置"过滤（保供率硬约束不满足的置灰并注明原因）；
- 基准配置（base case）可与最优并排显示差额（"优化节省 X%"）。

## 4. 结果可读性细节（客户视角）

- 所有表格**数字右对齐**，单位写在表头而非每格；
- 大数字用千分位，比率统一 %（保留 1 位小数），金额按规模选 元/万元/亿元；
- 每个图表有"图/表切换"——我平台实现为：图（Plotly）+ 数据表同节并列；
- 表格首行冻结、斑马纹克制（白/浅灰），无装饰性色彩。

## 5. 本平台的增强（HOMER 没有、我们必须有）

- 守恒审计徽章与置信度徽章（A-D + 归因）置于封面；
- 每个参数标注中文名+canonical+出处+等级（A/B/C）；
- 变更版本链、模型盲区卡、声明（LLM 不产生数值）；
- 系统架构图按参数卡**动态生成**（HOMER 是静态示意，我们按当前配置渲染）。
