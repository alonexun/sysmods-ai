## 0. Logo 使用规则（硬约束）

- Logo 文件：`Hy logo\hyapp sysmods ai 20261025 2_画板 1.png`（白底、黑字 sysmods + 绿色 AI，原始 13182×2756，宽高比 ≈ 4.78:1）；
- **只能以图片形式出现（`<img>`），禁止重绘/描摹/文字替代/拉伸变形**；
- 保持原比例：CSS 仅设定高度（页头 26-30px、报告封面 34-40px），宽度 auto；
- 前端放页头左侧；报告封面顶部居左；导出 HTML 用 base64 data-URI 内嵌（自包含）；
- 白底使用原样；深色底上必须垫白色圆角底板，不得给 logo 反色/换色。

## 1.1 紧凑密度规范（v1.1 新增——"有限空间呈现更多信息"）

- **设备卡片网格**：4 列（宽屏）/2 列（窄屏）grid，gap 10px；
- 卡片：顶部 2.5px 品牌绿边 + 设备中文名(11.5px 粗) + 英文小字(9px 灰) + 额定值(monospace 15px 深绿) + 最多 3 行 key-value 小字(10px)；
- 表格密度：行高 26px、字号 11px、padding 5px 10px（替换 v1.0 的 30px/12px/8-12px）；
- 参数表值与单位**同格**（`800 kW`），省一列；
- 分区标题 15px、卡片标题 12px；章节间距 28px；
- **信息优先级**：设备卡片(视觉) > 关键参数行 > 完整参数表（后者可折叠/靠后）。

## 2. 字体与排版

- 中文正文/标题：`"Microsoft YaHei", "PingFang SC", system-ui, sans-serif`；
- 数字/标签/章节号/表格表头：`"IBM Plex Mono", ui-monospace, Consolas, monospace`（等宽，数字右对齐的基础）；
- 不打包商业字体、不引用远程字体（离线自包含要求）；
- 封面大标题：28px/字重 700/紧凑；一句话目的陈述 14px；元信息行等宽 11px；
- 正文字号 13px，表格 12px，注释 11px；行高 1.55。

## 3. 空间与形状

- 内容最大宽度 **1080px** 居中，页边距 24px；
- 卡片圆角 10px、边框 1px `--hairline`、阴影仅封面与摘要卡（`0 2px 10px rgba(15,23,42,.06)`）；
- 章节间距 36px，章节内块间距 16px；表内行高 30px；
- 每章编号 + 标题 + 细分隔线（nTop 证据章节风格）。

## 4. 组件规范

- **封面**：白底大卡片 + 顶部 4px 主色条 + 项目名 + 元信息（会话/日期/版本/模型标注）+ 徽章组；
- **摘要 KPI 卡**：3-4 列网格，大数字（等宽 26px 主色）+ 中文标签 + 单位 + 小注；
- **提示卡**：`--brand-tint` 底 + 3px 主色左竖线（用于一句话结论/口径说明/降级提示）；
- **表格**：表头 `--panel` 底 + 等宽大写风格字 + 行细分隔线 + 白行 + 斑马纹可选浅灰；数字右对齐；关键行（最优/合计）主色底纹或加粗；
- **徽章**：圆角胶囊，PASS 绿 / FAIL 红 / 置信度 A 绿 B 蓝 C 橙 D 红；
- **架构图**：组件圆角块（电源浅蓝/电解浅绿/储能浅黄/化工浅粉/终端浅灰）+ 总线色连线 + 中文设备名+额定值；
- **按钮（前端）**：主按钮主色白字、次按钮白底主色边、危险操作需二次确认；
- **打印**：`@media print` 去导航/阴影，表格 `break-inside: avoid`，链接显 URL。

## 5. 禁忌（IBCS 红线）

- 禁止大面积渐变背景、装饰性彩色图标、阴影堆叠；
- 禁止饼图/仪表盘/3D 图；
- 禁止把 C 级先验结果画成与 A 级相同的实心样式（须标注）；
- 禁止用"浅一号蓝色"表达预测（用斜纹或文字标签）。
