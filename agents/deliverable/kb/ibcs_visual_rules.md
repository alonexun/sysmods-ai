# IBCS 视觉与信息设计规则（交付物 Agent · 视觉基准 KB）

> 来源：IBCS Association（ibcs.com，CC BY-SA）；参考实现：ai-data-agents/skills/databricks-app-design/references/ibcs-notation.md（2026-10-25 抓取整理）
> 用途：报告/图表的**视觉判断规则**——什么该画、怎么画、什么必须删掉。
> 版本：kb-ibcs-v1.0 · 维护：交付物 Agent

## 1. SUCCESS 七条检查单（每份报告生成后逐条自检）

1. **SAY 传达信息**：核心结论放标题/摘要，不埋在图后面。每份报告摘要区必须有"一句话结论"（如"最优配置：光伏 800kW+风 1500kW+PEM 600kW，净 NPC 最优"）。
2. **UNIFY 语义统一**：同一含义 = 同一形状/颜色/线型/标签（全报告守恒=绿、异常=红、实际=实心、目标=虚线）。
3. **CONDENSE 提高密度**：需要一起比较的数据放同一视图（实际+目标+偏差），不拆散。
4. **CHECK 视觉诚信**：坐标不误导、不混单位、同组图表同刻度；缺失数据显式标注。
5. **EXPRESS 恰当图形**：按比较任务选图（见 §2）。
6. **SIMPLIFY 去装饰**：删无意义色彩/图例/网格线/立体效果；颜色只编码场景/类别/状态/偏差。
7. **STRUCTURE 结构完整**：分组不重不漏、顺序合理（摘要→配置→结果→经济→参数→附录）。

## 2. 图表选型（比较任务 → 图形）

| 任务 | 选择 | 本平台实例 |
|---|---|---|
| 时间序列 | 折线/柱状，时间从左到右 | 8760h 逐时功率、储氢罐位 |
| 结构比较 | 条形图（按值或业务结构排序） | 各路线产氢对比、成本构成 |
| 部分-整体 | 堆叠柱/结构表（**避免饼图**） | 发电构成、NPC 构成 |
| 与基准/目标偏差 | 偏差条+好/坏标记 | 优化前后 NPC/LCOA 对比 |
| 精确查数 | 表格（内嵌小条形/迷你趋势线） | 优化结果表、参数表 |
| 单 KPI | 大数字+单位+周期+基准对比+趋势 | 摘要卡片组 |

**优先：柱、条、线、表。禁用：仪表盘、甜甜圈、装饰性 3D。**

## 3. 场景标注（跨报告统一的视觉语义）

| 场景 | 视觉规则 |
|---|---|
| 实际值（仿真结果） | 实心/深色 |
| 基准/上一版 | 浅色实心或细虚线 |
| 目标/约束（如保供率 99%） | 虚线参考线 + 文字标注 |
| 预测/先验（C 级参数驱动结果） | 斜纹或明确"先验"标签——**不得仅"浅一号"** |

偏差方向必须注明"越高越好还是越低越好"（NPC/LCOA 低好；保供率/产量高好）。

## 4. 数字与单位格式（UNIFY 细则）

- 同一视图单位一致；表头写单位，格内不重复；
- 金额：≥1 亿用亿元、≥1 万用万元，其余元（千分位）；比率统一 %；
- 大数字卡片：值 + 单位 + 周期 + 比较基准 + 数据新鲜度；
- 缺失/不可算：显式 NaN 与原因（禁止以 0 冒充）。

## 5. 交付前视觉自检清单（写入 SKILL.md 的验收）

- [ ] 摘要区有一句话结论？
- [ ] 每个标题含"对象+指标+周期"？
- [ ] 颜色是否全部承载语义（无装饰色）？
- [ ] 表格能否替代某些图更清楚？（能用表就别画图）
- [ ] 同组图表同刻度？轴/基线/单位诚实？
- [ ] 打印/PDF 下表格不断行、配色可辨？
- [ ] 页面在桌面与手机均可读？
