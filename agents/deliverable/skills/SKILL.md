# 交付物 Agent 技能（v2.1 · 标杆知识库驱动）

## 输入
结果 JSON（kpi/econ/series/cons/confidence/opt_table）+ 参数卡 + 盲区卡 + 变更史。

## 必读知识库（生成前必须加载）
1. `kb/homer_report_structure.md` —— 章节与表格结构（优化表/现金流五类成本/明细表）
2. `kb/ibcs_visual_rules.md` —— SUCCESS 自检、图表选型、数字格式
3. `kb/report_design_tokens.md` —— 唯一视觉事实源（v1.1：品牌绿/logo 规则/紧凑密度/禁忌）
4. `kb/device_card_library.md` —— 设备卡片组件库（模块化：出现哪些设备就渲染哪些卡片）
5. `kb/params/cn_names.py`（`kb/params/`）—— 参数中文映射

## 执行流程
0. **品牌与密度（v2.1）**：页头/封面用 logo **图片原比例**（高 26-34px，禁改比例/禁文字替代/导出内嵌 base64）；主色=品牌绿 #52C41A（深绿 #2F8F46 用于正文强调）；**信息紧凑**——设备用卡片网格（4 列），表格行高 26px/字号 11px，值与单位同格；
1. **一句话结论先行**：最优配置 + 关键指标 + 主口径（净 NPC/LCOA/保供率），放封面下方提示卡；
2. **需求回顾 Recall**：正文第一章——用户目标原话 + 客户确认参数（**用设备卡片网格呈现**）+ 先验使用 + 变更史 + 目标口径 + 核对提示；
3. **章节按 HOMER 结构**：系统架构图（动态 SVG）→ 发电/制氢明细 → 成本明细（五类成本）→ 时序 → 优化表 → 参数中文表 → 变更史 → 盲区 → 声明；
4. **设备卡片化（模块化）**：按参数卡调用 `device_cards.py` 注册表——出现哪些设备就渲染哪些卡片；specs 槽位最多 3 行，更多信息走参数清单；
5. **视觉按 tokens**：颜色只编码语义；表格数字右对齐、值与单位同格；金额自动选元/万元/亿元；
6. **图 vs 表**：能表格说清的不画图；时序才用折线；构成用堆叠柱不用饼图；
7. **守恒/置信度徽章**：封面固定位置，FAIL 时报告顶部红条警告"结果不可用"；
8. **自检**：按 ibcs_visual_rules.md §5 清单逐项通过后输出；打印 CSS 必须存在。

## 数值纪律（不可妥协）
- 所有数值来自结果 JSON 模板注入，**LLM 不写任何数字**；
- 缺失值显式 NaN+原因，禁止 0 冒充；
- 图-文-表-计算书同源：任何 KPI 在四处出现必须一致。

## 输出
- `report.html` 自包含（内嵌 CSS/SVG，图表 CDN 可降级为表格）；
- Excel 计算书（openpyxl 公式可审计）；
- 对话卡片流摘要（前端复用同一 tokens）。
