# 场景需求 Playbook（需求分析 Agent · 分布式中心）

> 来源：Sysmods AI 方案 V1.1 分布式取值裁决 + 代码 SCENARIOS 沉淀
> 版本：kb-grillme-v1.0 · 维护：需求分析 Agent

## 场景识别与必需参数
| 场景 | 关键词 | 模板 | 必需参数（追问优先级最高） |
|---|---|---|---|
| 哨站/离网 | 哨站/边防/离网/无电 | T1 | 负荷均值与昼夜特性、光伏/风电容量、储氢容量、保供率 |
| 加氢/补能 | 加氢/补能/叉车/无人机 | T2 | 日加注量、储氢容量、电解功率、电网条件 |
| 绿氨 | 绿氨/合成氨/NH3 | T6 | 氨装置规模(t/h)或年产目标、储氢缓冲、风光容量、电网模式 |
| 绿醇 | 甲醇/绿醇 | T6-醇（后续） | CO2 碳源与成本、醇装置规模 |
| 氢冶金 | 冶金/DRI/还原铁 | T6-DRI（后续） | 吨铁耗氢、竖炉连续约束 |

## 通用必问（所有场景）
1. 项目地点/纬度（辐照与温度修正）；
2. 负荷曲线特性与保供率要求；
3. 项目寿命与贴现率（可研口径）；
4. 电网条件：离网 / 绿电直连（PPA 价+容量）/ 分时电价 / 现货；
5. 消纳与价格口径：氨/醇/氢售价与减碳收益归属。

## 绿氨专项追问
- 合成氨是传统 HB（最小负荷 50%+爬坡 8%/h）还是柔性氨？
- 储氢缓冲可接受规模（决定 HB 利用率 vs 投资的核心矛盾）；
- 氨消纳：长协定量 vs 不设限（决定优化口径：净 NPC 还是 LCOA）。

## 参数卡纪律
- 客户给的值标 A（仍过输入校验），默认/检索值标 B/C；
- 完整度 = 必需参数中 A/B 级占比，驱动进度条；
- **禁止为凑完整度编造数值**——缺什么问什么，或按裁决链给先验并标注。
