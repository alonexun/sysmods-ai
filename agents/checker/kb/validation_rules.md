# 校核规则库（校核 Agent · 物理/标准/输入三层）

> 来源：Sysmods AI 方案 V1.2 §7.10/§7.11 + 内核测试沉淀
> 版本：kb-checker-v1.0 · 维护：校核 Agent

## 1. 守恒与物理底线（硬拦截）
- 逐步电/氢/热/物料平衡：年误差 >0.5% 即 FAIL；
- 能量方向：产氢能量 ≤ 耗电、发电 ≤ 耗氢能量（效率>100% 必拦截）；
- 元素守恒：N/H/C/O/Fe 理论计量闭合（化工/冶金），效率损失单列弛放；
- NaN/Inf/负功率/负库存：定位到模块拦截。

## 2. 输入校验（信任但验证）
| 检查 | 规则 | 处置 |
|---|---|---|
| 物理值域 | 效率∈(0,1]（小数）、电解电耗 45-70 kWh/kg、SOC∈[0,1] | 违反拦截 |
| 量纲反算 | 由两个"确定值"反推隐含量（如装机×利用小时≠年产） | 指出矛盾推导 |
| 交叉一致 | 装机 vs 占地、产氢 vs 储氢+外购、预算 vs 设备清单 | G1 门内解决 |
| 先验偏离 | 关键参数偏离行业先验 >30% 或 2σ | **不否定，生成口径追问**；未解释暂降级 |
| 新鲜度 | 电价/政策/报价 >2 年 | 检索复核并提示 |
| 压力测试 | 敏感 A 级参数自动 ±15% 重算 | 结果稳健性进 G4 展示 |

## 3. 标准符合性（首批方向性清单，入库前逐条核实）
- GB/T 37244 / ISO 14687：氢气品质；
- GB 50516 / GB/T 34584 / ISO 19880：加氢站；
- GB/T 29729 / GB 4962 / GB 50177：氢系统安全；
- ISO 22734：电解制氢系统；
- IEC 62282：燃料电池；
- 发改 2023《投资项目可行性研究报告编写大纲》：报告章节模板。
**强制条文一票否决；推荐条文偏离须标注理由；符合标准≠正确。**

## 4. 历史错误案例（防再犯）
- PEM 产氢公式方向（m=P×η/LHV）；
- HB 爬坡下限不得 clamp 超过氢可用量；
- 床温显式欧拉在 dt>>τ 时发散（用步内解析解）；
- 守恒审计只查平衡不查方向——方向检查独立。
