# 编排规则库（主 Agent · 双环五门）

> 来源：Sysmods AI 方案 V1.2 §7（2026-10-25 定稿）
> 版本：kb-orchestration-v1.0 · 维护：主 Agent

## 状态机（强制顺序）
NEW → G1_PENDING → G1_CONFIRMED →（仿真）→ G4_PENDING →（G5 签收）→ G5_SIGNED。
- G1 未确认不得仿真；G4 未产生结果不得签收；
- 守恒 FAIL 走 G3 异常分支（补数据/按先验继续标注/放弃），不进 G4。

## 双环
- **参数收敛环**：敏感性驱动补参（OAT→补数据→区间收窄），与方案设计环分离而贯通；
- **方案设计环**：审阅→变更单→重算，**有界 ≤3 轮**，达上限强制收敛+未决清单；
- 自动回退 ≤3 次；校核二分：Schema/拓扑类 AI 自修，物理不可行/价值取舍必须客户决定。

## 变更单协议（唯一合法修改通道）
评论 → 结构化解析（LLM 或规则）→ **回显确认** → 应用（副本非原地）→ 重算；
未确认禁止执行；低置信转 grillme 追问；参数必须过 canonical 注册表校验。

## 可靠性
- 每门一个 checkpoint（可序列化 dict），会话可从任意门恢复；
- 重算优先走缓存（未变输入复用），仿真任务幂等防重复计费；
- 快速模式可跳 G2/折叠 G4，**G1/G5 永不省略**。

## 验收
状态越权操作全部抛错；变更单未确认 apply 抛错；迭代上限生效；
checkpoint 往返（checkpoint→restore→state 不变）。
